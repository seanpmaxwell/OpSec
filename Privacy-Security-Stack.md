# Privacy & Security Stack

## Browsers

- **Brave:** A privacy-focused browser that I use as my primary browser.
- **Mullvad Browser:** A privacy-focused browser designed to minimize tracking and fingerprinting. I use it for more privacy-sensitive browsing.

## VPN

- **Mullvad VPN:** A privacy-focused VPN service that does not require personal information to create an account (no email address or password required). I like it because it accepts cryptocurrency payments, allowing me to purchase subscription time without using traditional payment methods. Mullvad has a strict no-activity-logging policy, is headquartered in Sweden, and operates under Swedish and applicable EU privacy laws.

## Operating Systems

- **Kicksecure:** A security-focused Linux distribution based on Debian. It supports Live Mode, allowing sessions to run without retaining changes after shutdown. It can be installed on bare-metal hardware, run from a USB drive, or used in a virtual machine (VM).

- **Whonix:** A privacy- and security-focused operating system based on Kicksecure (which is itself based on Debian). It is designed around two isolated virtual machines: Whonix-Gateway and Whonix-Workstation. The Gateway routes the Workstation's internet traffic through the Tor network. This architecture helps prevent the user's real IP address from being exposed, even if the Workstation is compromised.

- **Tails OS:** An amnesic operating system designed to run from a USB drive. It leaves minimal traces on the computer after shutdown, provided it is used without persistent storage. While not particularly practical as a daily operating system, it is extremely useful when temporary, non-persistent sessions are needed. One example is securely transferring sensitive files (such as account recovery keys) from an online account to an encrypted USB drive.

## Laptops
- **Thinkpad T430s**: The t430 was the last generation of Thinkpads to feature a physical Wifi toggle switch. 

## Office Suite (Email / Password Manager / File Sharing)

- **Proton:** A suite of privacy- and security-focused online services, including Proton Mail, Proton Pass, Proton Drive, and Proton VPN. Proton AG is headquartered in Switzerland, and its services are subject to Swiss law and applicable privacy regulations.

## AI / LLMs

- **Venice AI:** A privacy-focused, multi-model AI platform offering a wide selection of language models and other generative AI tools. It also offers access to Pro features through staking Venice tokens (VVV). Staking at least 100 VVV currently qualifies users for Pro features, providing an alternative to a conventional recurring subscription. Note: this benefit is subject to change at Venice's discretion.
