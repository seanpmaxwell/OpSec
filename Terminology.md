# Terminology 

#### OpSec (Operational Security)
User defined behavior for keeping digital information/activity secure.

#### Cyber Security
Software for keeping digital information/activity secure.

### IP (Internet Protocol) Address
A unique identifier assigned to a digital device (e.g. computer, modem, server etc). 

#### ISP (Internet Service Provider)
Provides a user with internet access (i.e. Xfinity). 

#### DNS (Domain Name Service)
Maps a user friendly name (e.g. google.com) to a server's IP address. 

#### VPN (Virtual-Private-Network)
Combination of services used to protect a user from entities which could normally observe one's identity/activity. Typically, in the context of a personal VPN subscription (e.g. Nord, Proton, Brave etc), this involves a desktop (or mobile) application which encrypts a users activity so it cannot be observed by an ISP and redirects all requests to a VPN's server, thus masking which websites are visited by the user to the ISP and the IP address of the user to the website. Two things worth knowing, the ISP can still determine the amount of data being requested, and because all data is redirected to a VPN's server, the ISP can determine which VPN service is being used.
